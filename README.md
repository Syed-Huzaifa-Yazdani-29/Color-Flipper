# Color Flipper

## 🎨 Overview
The **Color Flipper** is a simple web application that changes the background color randomly when a button is clicked. This project is perfect for beginners learning JavaScript DOM manipulation and event handling.

## 🚀 Features
- Randomly generates a background color on button click.
- Smooth color transition effect.
- Simple and lightweight UI.
- Built using HTML, CSS, and JavaScript.

## 🛠️ Technologies Used
- **HTML** - Structure of the webpage.
- **CSS** - Styling and layout.
- **JavaScript** - Logic for changing colors dynamically.
